# SID KEDIREN - Sistem Informasi Desa Kediren

Sistem manajemen kependudukan dan pelayanan desa digital untuk Desa Kediren, Kecamatan Lembeyan, Kabupaten Magetan.

## Fitur Utama
- Manajemen Data Penduduk & Keluarga
- Sistem Mutasi Warga (Pindah Datang, Pindah Keluar, Pecah KK, Kelahiran)
- Arsip Digital Kartu Keluarga
- Dashboard Statistik Kependudukan
